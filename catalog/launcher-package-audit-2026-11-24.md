# X16 For All Time package audit

November 24, 2026 Central time. The baseline at 367af22 contained 214 programs and one eligible entry. The updated catalog contains 214 programs, 30 eligible entries and 35 verified packages. Of these, 29 entries became eligible and 184 remain browse-only.

All 214 source records were reviewed. All 187 catalog records with an original forum topic encountered HTTP 403. All 52 distinct extensionless forum attachment URLs checked also returned HTTP 403. The audit used reachable maintainer releases, documentation and author-linked files for positive verification. A blocked forum topic can still contain a usable official package.

Every advertised artifact was downloaded and inspected. ZIPs were checked for integrity, compatible member paths and exact-case startup filenames. The launcher offers a PRG choice for archives with multiple legitimate startup programs and no author-designated default.

## Launcher smoke test

X16 For All Time 0.7.11 ran under Wine with the generated feed served locally and downloads fetched from their original HTTPS URLs. The Downloadable only filter returned 30 of 214 entries. Install to Start preserved the bytes of the BASLOAD direct PRG and every file in the Alter Ego, Crazy Solitaire, and X16 Office Suite ZIPs. Crazy Solitaire tested an extensionless author-linked URL. The Office Suite chooser selected CALENDAR.PRG from four candidates. Download and launch opened X16Emu R49 for Alter Ego and Crazy Solitaire. Forum attachments could not be tested in the launcher because their HTTP GETs returned 403.
