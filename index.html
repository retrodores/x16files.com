Checkout X16 For All Time 1.0 for Windows

X16 For All Time (F.A.T.) is a desktop client for this catalog. Install or register X16Emu, then open the X16 Files tab. Choose Download and launch to try a program, or Install to Start to keep it for later.

Requires Windows 10 or later and .NET Framework 4.8 or later.

Get the Windows installer User guide Video walkthrough Forum announcement

F.A.T. is early software, and we’d like your feedback. We’re exploring how to make X16Files.com more useful as the launcher’s software catalog. What would make it easier to find or install a program? Report an issue or suggest an improvement.

To help develop F.A.T., start with the contributor guide in the F.A.T. GitHub repository. If you’d like to build a native Linux or macOS client, the port specification describes the launcher’s behavior and how it reads the X16 Files catalog.
